# CE4703 – Assignment 2: Card Game

## Project Description
This project involves developing a console-based card game in C using user-defined data types and dynamic data structures. The game simulates two players taking turns playing cards that match the suit or rank of the top card in the played deck.

The game continues until one player has no cards remaining.

## Technologies Used
- C Programming Language
- Microsoft Visual Studio
- Doxygen Documentation

## Key Features
- Create standard decks of cards using structures and enumerations.
- Support multiple packs of 52 cards.
- Use dynamic memory allocation to manage card decks.
- Shuffle and sort cards.
- Deal eight cards to each player.
- Simulate turns based on matching card suits or ranks.
- Display each player's cards and game progress.
- Reshuffle the played cards when the hidden deck becomes empty.

## Project Documentation
The project includes modular source and header files, Doxygen comments documenting the data types and functions, and generated HTML documentation.

## How to Run
Open the Visual Studio solution, build the project, and run the application. Enter the number of card packs when prompted and follow the game progress in the console.

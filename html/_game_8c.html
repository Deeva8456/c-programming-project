Detailed Description

Implementation of gameplay mechanics for the two-player card game.

This file contains the full game logic used by main.c, including:

  • Deck shuffling
  • Deck sorting
  • Dealing cards to players
  • Handling the discard and hidden piles
  • Automatically reshuffling when the hidden deck becomes empty
  • The complete turn-based game loop

The game works with the dynamic CardDeck type (singly-linked list). Each player draws or plays depending on whether they have a matching card.

void createCardDeck ( CardDeck * deck,
int packs )

Create a deck containing packs * 52 cards in standard order.

Create a deck containing the specified number of standard packs.

Parameters
deckPointer to the CardDeck to populate.
packsNumber of 52-card packs (>= 0). If packs <= 0 the deck is left empty.

The order chosen is: for each pack, suit CLUB..DIAMOND; for each suit, rank TWO..ACE. Cards are appended to the bottom so the first card inserted will be at the top if removed with successive removeTopCard calls depending on whether you push to top/bottom in your dealing logic.
